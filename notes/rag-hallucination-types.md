# 幻觉（Hallucination）：幻觉类型

> 包括无依据编造、引用错配、数字错误、实体混淆和把推断说成事实。

## 六种典型形态
无依据编造：答案里的实体在检索片段中完全不存在。引用错配：结论本身成立，但挂的 doc_id 指向一段并不支持它的文字。数字与单位错误：金额、比例、日期被改写，或万元与元、月与年换算错位。实体混淆：同名不同主体、同名不同版本被合并成一个对象。推断当事实：由两条证据推出第三条结论，却用肯定语气直接陈述。过期事实：证据内容无误，但生效时间早于问题问的时间点。

## 可自动检测的特征
编造类算答案实体在上下文中的字符串与向量覆盖率，低于阈值即告警。引用错配用 NLI 模型判断「被引段落 → 该句」是否蕴含，聚合成 Citation precision。数字类用正则抽出全部数值单位对，回原文做精确匹配。实体混淆比对答案实体的 canonical id 是否落在上下文实体集合内。推断类检测句子与证据的词汇重叠低却不含「可能」「推测」等限定词。过期类比较片段的 effective_date 与问题时间范围。

## 分类决定修哪一层
编造和过期指向知识源与更新机制，引用错配指向检索与重排，推断类和语气问题指向 prompt 约束，数字类多半要在生成后加一道校验。不分类就只能整体调 prompt，反复试错。
